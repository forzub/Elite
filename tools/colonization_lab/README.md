# colonization_lab — офлайн-лаборатория истории и экономики колонизации

Маленькая детерминированная модель, которая **объясняет и проверяет канон** колонизации до 3126 года. Она не генерирует вселенную заново.

Вход:
- `canon/missions.json` — паспорта миссий и исторические якоря;
- `canon/world.json` — колонии, аванпосты, маяки, обиды, хронология гипера, якорь Земли-3126;
- `canon/cultures.json` — культуры источников и фильтры набора;
- физический каталог `src/assets/data/galaxy_details` — читается через `endowment.py` и `tools/universe_generator/resource_audit.py`.

Выход: `out/lab_state_3126.json` и `out/lab_report.md`.
- Хроника каждой миссии: якоря канона плюс события, заполняющие пробелы.
- Вахта и крио: минимальная вахта, циклы, наследственная вахта, хранители, сон владельцев.
- Инженерная проверка каждого корабля (`physics.py`).
- Колонии 3126: рост, способности, богатство.
- Экономика: запасы и потоки, импорт и экспорт, цены, партнёры.
- Стандартные шоки: последствия против контрольного прогона.
- Социальные ответы на одинаковый шок.
- Реакции на Землю-3126.
- Отношения и сеть маяков по годам.

Только стандартная библиотека Python 3.

## Команды

```bash
cd tools/colonization_lab
python lab.py                      # канон: seed 3126 -> out/
python lab.py --seed 7 --out /tmp/x  # другой seed меняет только «заполняющие» события, не якоря
python export_runtime.py --write   # регенерировать блок canon в src/assets/data/galaxy/generation_ships.json
python lab.py --check-dataset      # runtime-файл не разошёлся с каноном?
python endowment.py                # индексы ресурсов 60 систем из каталога
```

## Доказательство детерминизма

Одинаковый вход и seed дают байт-в-байт одинаковый результат: нет часов, нет несидированного RNG, итерация отсортирована, RNG миссии = `seed * 1000003 + crc32(id)`.

```bash
python lab.py --out runA && python lab.py --out runB && diff -r runA runB && echo IDENTICAL
```

Программа печатает sha256 от JSON и отчёта. Для канона:

```text
seed=3126 missions=36 colonies=22 sha256=7ebbcd7a44b79e6ee28d56fde94c5ca4ad7734860f14611427b84386e148f4ff  (прогон 2026-11-01; меняется при любом изменении canon/*.json)
```

## Правила

- **Якоря** (`anchors` в `missions.json`) — записанная история. Модель применяет их как есть: смерти, эффекты на когорты и оси, численность на прибытии. Модель не может их переписать.
- **Заполняющие события** (`source: simulated`) — только мелкие: чёрный рынок, саботаж, попытка мятежа, технократия, чистка, примирение, каста хранителей, цикл анекдотов. Они seed-зависимы.
- Если тенденция режима модели расходится с каноническим режимом, отчёт ставит `≠`. Это значит, что канон держится на конкретном событии, и его нужно сохранить якорем.
- Даты прибытия выводятся из расстояния в каталоге. Если средняя скорость выше потолка эпохи, это помечается флагом. Исправленные даты хранят старое значение в поле `authored`.
- Население 3126 — цель канона. Лаборатория подбирает темп роста и помечает неправдоподобное (> 1.2 %/год без гипер-миграции, > 3 %/год).

## Состав

| Файл | Что делает |
|---|---|
| `endowment.py` | вода, летучие, He-3, металлы, стратегическое сырьё, агро, поселение — перцентили по каталогу |
| `physics.py` | порядок величины: сухая и полная масса, отношение масс, He-3, атмосферы гигантов, ускорение, мощность струи, радиаторы, вердикт |
| `lab.py` | вахта, крио, общество (Colonycore v2), колонии, сеть маяков, экономика, шоки, ответы, проверка датасета |
| `export_runtime.py` | канон → `generation_ships.json`: все legacy-поля сохранены, добавлен блок `canon` |

Документы: `Notes/History/COLONIZATION_CANON_3126.md` (справочник), `Notes/Colonycore/COLONYCORE_V2.md` (модель общества).

## Синхронизация Markdown и runtime

Источник истины — `canon/*.json`.
- `generation_ships.json` генерируется отсюда и проверяется командой `--check-dataset`.
- Markdown-справочник пишется по отчёту. При изменении канона нужно перезапустить лабораторию и сверить таблицы §4 и §8 справочника с `out/lab_report.md`.
