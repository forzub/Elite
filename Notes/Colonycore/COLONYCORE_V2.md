# Colonycore v2 — модель общества колонии

**Статус:** предложение к контракту, 2026-11-01. Реализация-эталон: `tools/colonization_lab/` (`canon/cultures.json`, `lab.py`).
**Заменяет:** `Notes/Colonycore/Colonycore.md` (v1). Файл v1 сохраняется как история; поля v1 отображены в v2 в §6.

## 1. Оценка v1

**Что хорошо:**
- Разделение «норма (BaseCulture) / текущее состояние (ErgoState)».
- Давления (Pressures) как источник дрейфа.
- Событие как первичный объект.
- Принцип «сделать одну эталонную колонию».
- Конкурирующие модели легитимности (`legitimacy_model`) — это лучшее в v1.

**Что избыточно и дублируется:**
- `ErgoState` повторяет всю BaseCulture. Хранить два полных вектора по 30 осей — значит хранить шум. Достаточно нормы и отклонений (drift), производных от давлений.
- `ThreatProfile` (18 полей) почти целиком выводим из истории и среды: `habitat_breach` следует из типа хабитата, `unknown_presence` — из события вроде IRON-SHIELD-2. Хранить его как свободные числа — значит позволить ему противоречить истории.
- Пары синонимов:
  - `formality` и `tradition_grip`;
  - `paranoia`, `external_trust` и `xenophobia_pressure`;
  - `control_acceptance` и `external_authority_acceptance`;
  - `collective_purpose` и `holy_mission`;
  - `siege_identity` и `security_buffer_drive`.
- `Constraints` дублирует физический каталог: гравитация, ресурсы и изоляция уже лежат в `galaxy_details`.

**Чего не хватает:**
1. **Когорт.** В v1 только `population_groups` с долей. Нет власти, доступа к ресурсам, образования, обиды, доли бодрствующих. Без них нельзя выразить ни «возвращение спящих хозяев», ни «инженеры стали элитой», ни классовый конфликт.
2. **Быта.** Нет осей отношения ко времени (пунктуальность, сиеста, ночная жизнь), к начальнику (почтение против иронии), к правилу (обход как норма), к семье/клану, к жалобе, к шутке над бедой.
3. **Фильтра набора.** Культура колонии в v1 задаётся как «как это общество живёт», а должна выводиться из страны, спонсора, отбора и рейса.
4. **Механизма ответа на шок.** Производные метрики v1 (`resistance_intensity` и т. п.) не говорят, **что общество сделает**.
5. **Связи с экономикой.** Ни одна ось v1 не влияет на производительность, надёжность контракта, торговлю или скорость восстановления.

**Может ли v1 выразить сиесту, привычку обходить правила, культ формальности?**
- **Сиесту — нет.** Её можно лишь размазать по `leisure_value + comfort_priority + schedule_rigidity`. Но у этих полей нет поведения: они не меняют реакцию на начальника, ничего не делают в смешанной вахте и не влияют на производство.
- **Обход правил — нет.** Ближайшее — низкий `control_acceptance`, но это другое. Бразилец с jeitinho не против правил вообще: он считает нормальным их обойти «по-человечески», а это идёт вместе с высоким уровнем общественного договора.
- **Культ формальности — частично** (`formality`). Но без последствий: комиссия на 5 лет, реестр договоров как экспортная услуга, медленный старт восстановления.

Вывод: v1 нужно не дополнять ещё 15 осями, а **сжать**. Нужны быт плюс когорты плюс механизм ответа.

## 2. Состав v2

```text
SocietalLine
  origin            миссия(и), год, источник культуры (ссылки в canon/missions.json)
  cohorts[]         малое состояние на когорту
  culture           24 оси быта и ценностей (норма) + drift (отклонение)
  institutions      режим + многомерная власть
  memory            якорные события, обиды, мифы (список, а не числа)
  environment       ССЫЛКА на систему каталога + выведенные индексы (не хранится)
  capabilities      9 областей (выводятся)
  economy           запасы/потоки (см. лабораторию)
```

### 2.1 Когорта (минимальное состояние)

| Поле | Смысл | Пример влияния |
|---|---|---|
| `share` | доля населения | вес в культуре населения |
| `power` | институциональная власть | вес в культуре решений, тенденция режима |
| `awake` | доля бодрствующих (в рейсе) | хранители против спящих |
| `grievance` | обида 0..100 | мятеж, саботаж, чистка |
| `cohesion` | внутренняя сплочённость | раскол на кланы |
| `culture` | своя культура когорты (фильтр набора) | разные сектора на одном корабле |

Архетипы:
- `patricians` — владельцы;
- `command` — командование;
- `engineers` — инженеры;
- `scientists` — учёные;
- `security` — охрана;
- `workers` — рабочие;
- `settlers` — поселенцы;
- `coerced` — подневольные: каторга, долги, «лишние»;
- `faithful` — духовенство и идеологический актив.

Ресурсный доступ и образование здесь не отдельные поля: они выражены через `power` и архетип. Доступ к ресурсам добавляется в экономике, если понадобится.

### 2.2 Культура: 24 оси

Шкала 0..100, гипотеза, **не генетика**. Каждая ось обязана влиять хотя бы на одно правило (§3). Ось без следствия удаляется.

| Группа | Ось | Пример высокого значения |
|---|---|---|
| Время | `clock_time` | «пять минут опоздания — неуважение» |
| | `midday_pause` | сиеста или долгий обед легитимны |
| | `night_life` | вечер — главное социальное время |
| Правило | `rule_bending` | обойти — нормально (jeitinho, блат, гуаньси, «смекалка») |
| | `formalism` | справка важнее дела; процедура священна |
| | `order_love` | порядок как ценность (противоположность — терпимость к хаосу) |
| Власть | `power_distance` | почтение к начальнику |
| | `irony_to_power` | анекдот о начальнике, публичное послушание |
| | `say_no` | способность прямо сказать «нет» |
| | `state_trust` | доверие институтам |
| Свои и чужие | `kin_first` | семья и клан выше учреждения |
| | `hospitality` | гостеприимство |
| | `privacy` | приватность |
| | `outsider_trust` | доверие чужим |
| | `open_conflict` | публичный спор нормален (противоположность — сохранить лицо) |
| | `grievance_memory` | длинная память обид |
| Хозяйство | `status_display` | показное потребление |
| | `thrift` | бережливость |
| | `improvisation` | инженерная импровизация (противоположность — план) |
| | `risk` | терпимость к риску |
| Беда | `gallows_humor` | превратить трагедию в анекдот |
| | `complaint_ritual` | ворчание как ритуал, а не мобилизация |
| | `hardship_pride` | героизация лишений |
| | `collective_duty` | долг перед общим делом |

**Кластеры** — это не новые поля, а комбинации, которыми удобно думать:
- **Сиеста** = `midday_pause` + `night_life` + низкий `clock_time` + `kin_first`. Добавьте наследие жары и легитимность «обед — святое».
  - В смешанной вахте с жёсткими корабельными часами такая когорта копит обиду пропорционально рассогласованию с часами командующей когорты. Часы командования медленно побеждают.
  - Реакция на «начальник требует сейчас» = `say_no` против `power_distance`, смягчённые `irony_to_power`: улыбнуться, согласиться и сделать после обеда.
- **Блат / jeitinho** = `rule_bending` + `kin_first` + `improvisation` − `formalism`. Ответ на шок — «достать по знакомству», в мирное время — неофициальная наценка.
- **Культ формы** = `formalism` + `clock_time` + `state_trust`. Ответ на шок — комиссия. Восстановление начинается медленно, зато контракт надёжен, а реестр становится экспортной услугой.
- **Осаждённая крепость** = низкий `outsider_trust` + `grievance_memory` + `collective_duty` + `power_distance`. Ответ на шок — искать внутреннего врага.

### 2.3 Конвейер формирования (founding profile)

```text
самообраз (мифы, самоирония, поговорки, свои анекдоты, быт)
+ карикатура соседей (анекдоты, стереотипы, сатирические типажи, обиды)
+ дневной ритм и институты эпохи запуска
-> культура источника (canon/cultures.json, гипотеза)
+ классовый состав, город/деревня, образование, профессии
+ ФИЛЬТР НАБОРА МИССИИ (cohort_filters): кого берёт спонсор
-> культура когорт -> культура населения (вес share) и культура решений (вес power)
```

Две миссии одной страны различаются **фильтром**. TIANHE-1 (поселенцы из перенаселённых провинций, 45 % крио, 190 лет) и CELESTIAL-DESTINY-1 (85 % крио, 87 лет, без рождений) стартуют с одной культуры источника. Приходят они разными: первая — с наследственной вахтой и хранителями, вторая — «самая земная». DHARMA-1 (каторжная треть, генный массив у жрецов) и DHARMA-2 (реформаторский набор, гибкие касты) различаются так же.

### 2.4 Институты (многомерно, не один индекс)

- `regime` — метка для людей: `party_technocracy`, `shareholder_agora`, `caste_theocracy` и т. п.
- `legitimacy` — 0..100.
- `power` — распределение по когортам.
- `keeper_index` — власть наследственной вахты над спящими.
- `owner_sleep_years` — сколько спали владельцы.

Режим **не задаётся страной**. Лаборатория вычисляет тенденцию режима из власти когорт и культуры. Канонический режим — это якорь. Расхождение тенденции и якоря — сигнал: канон держится на конкретном событии, и оно обязано быть записано (Пакт Сварога, кастовая реформа DHARMA-1, пробуждение клира NJ).

### 2.5 Память вместо ThreatProfile/NarrativeProfile

Хранятся события-якоря (`canon/missions.json → anchors`) и обиды между колониями (`world.json → relations_anchor`). «Страх неизвестного» у Цитадели — не число, а событие IRON-SHIELD-2 плюс его эффекты на оси. Мифы — текст в справочнике. В числах они нужны только там, где меняют правило.

### 2.6 Среда — только из каталога

Индексы `water`, `volatiles`, `he3`, `metals`, `strategic`, `agri`, `settle` вычисляет `endowment.py` из `galaxy_details` (перцентиль по 60 системам). Хранить их в обществе запрещено: иначе они разойдутся с физикой.

## 3. Правила (где оси работают)

| Механизм | Оси | Где в коде |
|---|---|---|
| Обида от корабельных часов | `clock_time`, `midday_pause` (рассогласование с командующей когортой); снижает `gallows_humor` | `Voyage.run` |
| Замкнутый мир | дрейф `order_love` ↑, `privacy` ↑, `outsider_trust` ↓, `formalism` ↑, `thrift` ↑ | `Voyage.run` |
| Случайные события в пробелах канона | черный рынок ← `rule_bending` × дефицит; чистка ← `power_distance` × обида × охрана; примирение ← `hospitality`; цикл анекдотов снижает обиду ← `gallows_humor` | `Voyage.emergent` |
| Тенденция режима | власть когорт × `say_no`, `collective_duty`, `power_distance`, `kin_first`, `status_display` | `Voyage.regime_tendency` |
| Способности колонии | например, электроника ← `clock_time`, `order_love`, `say_no` (контроль качества), `formalism`; добыча ← `improvisation`, `risk`, `hardship_pride` | `colony_profile` |
| Ответ на шок (10 каналов) | пайки и мобилизация; докупить у соседей; спекуляция; чистка; месть; комиссия; обходной путь; шутить и терпеть; исход; молитва — каждый с весами осей + режим + тип шока + ситуация (альтернативные поставщики, тяжесть, богатство, изоляция) | `social_response` |
| Реакция на Землю-3126 (9 вариантов) | оси + расстояние до Сола + военный потенциал + торговые партнёры + обиды + внутренний раскол | `earth_reaction` |

## 4. Проверка выразительности

Шесть одинаковых шоков применены к 21 колонии. Различных первых ответов — 6–9 на шок (отчёт лаборатории §7). Примеры одного шока «главный рудник уничтожен»:
- Новая Европа — комиссия, регламент: `formalism`↑ + режим;
- Сельта-Верде, Новая Индия — «достать по знакомству»: `improvisation`↑, `rule_bending`↑, `kin_first`↑;
- Тяньхэ, Гармония — пайки и мобилизация: режим + `hardship_pride`↑ + `collective_duty`↑;
- Цитадель, Новая Карма — найти внутреннего врага: `outsider_trust`↓ + режим + `grievance_memory`↑;
- Шахта Альфа, Свободные поселения — бизнес взвинчивает цены: `rule_bending`↑, `state_trust`↓, режим;
- Новый Шанхай, Агора — спокойно докупить: альтернативные поставщики + `hospitality`↑;
- Ново-Фиваида — молитва;
- Пояс Раздора — кланы уходят.

Если бы ответы совпали, модель была бы признана невыразительной (критерий задачи). Совпадений по причинам нет.

## 5. Ограничения (честно)

- Колониальный дрейф 3126 грубый: сдвиги от среды и режима плюс якоря. Подробный дрейф по десятилетиям колонии не моделируется — это следующая итерация, если появится потребность в геймплее.
- Значения осей — экспертная гипотеза из самообраза и карикатур (см. `D:/tmp/COLONY_PSYCHOLOGY_REVIEW.md`), а не измерение.
- Индивидов нет. Когорты, события, пороги — как требует `GENERATION_SHIP_SETTLEMENT_SIM.md` §15.
