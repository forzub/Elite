# Elite 3126 — HTML-справочник кораблей

Открыть `index.html` обычным браузером. Сайт полностью статический и не требует HTTP-сервера.

Главная страница: блок → производитель → корабль; справа паспорт, дизайн-доктрина, вооружение и замены.
Кнопка «Открыть сборку» ведёт на отдельную страницу корабля `ship.html?id=...`.
Там слева функциональное дерево `35A1...`, справа паспорт выбранной детали с приоритетом на габариты.
Эскизы строятся автоматически из паспортных размеров; это компоновочные эскизы, не финальная геометрия.
Рамы кораблей пока намеренно не являются паспортными деталями.

## Покрытие флота и предложения справочника

Главная страница без параметра (`index.html` или `index.html?view=coverage`) открывает **«Покрытие флота»**:
матрица блок × роль (● есть паспорт, ◆ добавлено справочником, ◐ роль закрывается чужим корпусом), счётчик
«сколько моделей рисовать» (большие корпуса, варианты, малые аппараты) и список новых деталей.

Записи со `status: "PROPOSAL (reference)"` добавлены в `data.js` вручную, а не из канона
`tools/colonization_lab/canon/*`. Это 17 паспортов (1 новый корпус ТС-6, 13 вариантов существующих корпусов, 3 малых аппарата)
и 2 детали (`srw.reactor.sr26`, `kern.mine.cutter`). У каждой такой записи есть блок `reference`: исходный корпус варианта,
заметка о переделке, взаимозаменяемость, баланс мощности и охлаждения по правилам `ship_designer.py` и открытые вопросы.
Матрица хранится в `data.js → coverage`. Если `data.js` перегенерируют из канона, эти записи нужно сохранить или перенести в канон.

## Proposal ships (2026-11-06)

`tools/build_proposals.js data.js` re-adds the "PROPOSAL (reference)" ships, parts and the coverage matrix (idempotent: strips earlier ones first) - run it after any regeneration of `data.js` from the canon. `tools/render_check.js` renders every ship / part with a stub DOM.
