# Маршрутное окно и программы точек — проект (PROPOSAL, 2026-11-06)

Статус: PROPOSAL, на рассмотрении автора. Нормативный контракт навигации остаётся в
`NAVIGATION_V2_EXECUTION_ARCHITECTURE.md`; этот документ описывает слой маршрута над ним.

Заказ автора (2026-11-06): «если точка касается хаба, планеты или поселения — другое окно, где
каждая точка имеет свою программу… пауза миссии… кнопки „просчитать маршрут“ и „старт“… прокладка
и движение к кораблю… учёт остатков топлива и рекомендации по заправке… если топлива не хватает,
планировщик сам добавляет точки; для прыжка планировщик сам добавляет промежуточные точки».

## 1. Что уже есть (основа)

- `RoutePlan` / `NavigationWaypoint` (`RoutePlan.h`): точки с ролью (промежуточная / финиш), цель
  (`RouteTargetRef`: свободная точка, тело, хаб, корабль, инфраструктура), профиль прибытия
  (`NavigationArrivalProfile`: безопасная зона / следование / строй / парадный строй — сейчас
  применяется ко ВСЕМ точкам, а имеет смысл только для корабля), `stopAction` ("refuel").
- Планировщик `route::planRoute` (официальный / неофициальный маршрут, зоны из
  `route_zones.json`), плечи `Hub / Orbit / Point`; сервер летит плечи (`GameSimulationRoute.cpp`).
- Автопилот к телу с посадкой (дикая площадка — автоматический выбор; поселение `site:<id>` — площадка 1).
- Доковый планировщик и автопилот стыковки (в стабилизации, в хабе).
- Заряд J (`JDrive.h`): расход по правилу, ёмкость Cobrett 3 т; заправка на хабе пополняет его.

Нет: взлёта с поверхности, межсистемного прыжка в рантайме, сделок (F8 без покупки / продажи),
стыковки вне модуля Высокого, встречи с летящим кораблём.

## 2. Окно

Одно окно маршрута на карте (там же, где список точек). Строка = точка:

```
 #  ЦЕЛЬ                    ПРОГРАММА                       ДЕЙСТВИЯ НА МЕСТЕ        ⏸
 1  Высокий (хаб)           стыковка                        заправка, ремонт         ·
 2  Луна (тело)             выход на орбиту 100 км          —                        ·
 3  Шеклтон (поселение)     посадка → взлёт (промежуточная) забрать: лёд 20 т        ⏸
 +  Байконур (хаб)          стыковка                        [добавлено: заправка]    ·
 4  «Кобретт-7» (корабль)   встреча: строй, 300 м           —                        ·
 ─────────────────────────────────────────────────────────────────────────────────────
 [РАССЧИТАТЬ]  [СТАРТ]  [ПАУЗА / ПРОДОЛЖИТЬ]      время 3 ч 12 мин · заряд J 2.41 / 3 т · резерв 0.30 т
```

- Программа выбирается из списка, допустимого для типа цели (§3); действия — флажки и количества.
- ⏸ на точке = «миссия на паузе здесь»: автопилот довозит и отдаёт управление (ручной режим).
- Строки, вставленные планировщиком, помечены «добавлено» с причиной (заправка, промежуточная
  точка прыжка, обход зоны) — пилот может их удалить, тогда расчёт покажет, почему маршрут не сходится.
- РАССЧИТАТЬ строит маршрут и итоги, не трогая корабль; СТАРТ — исполнение; ПАУЗА / ПРОДОЛЖИТЬ —
  в любой момент (продолжение перестраивает маршрут от текущего места).

## 3. Программы по типу цели

| Цель | Программы | Действия на месте |
|---|---|---|
| Хаб | пролёт; стыковка | заправка, ремонт, торговля (разгрузить / загрузить из F8), ⏸ ручной режим по хабу |
| Планета / луна | выход на орбиту (высота); разведка с орбиты (витков, наклонение); посадка (автомат, дикая площадка) | для промежуточной: взлёт и продолжение |
| Поселение | посадка на площадку (поселения) | забрать / отдать груз, пассажиры, ⏸ ручной режим; промежуточная — взлёт после |
| Корабль | встреча: безопасная зона / следование / строй / парадный строй (+ дистанция) | ⏸ |
| Свободная точка | пролёт; остановка (стабилизация) | ⏸ |

Профили прибытия корабля (§1) показываются ТОЛЬКО для цели «корабль».

## 4. Встреча с кораблём

1. Цель рядом (та же стабилизация: тот же хаб / та же орбита в пределах ~20 км) → сразу доковый
   планировщик и автопилот в стабилизации до профиля встречи.
2. Цель в соседнем хабе / на другой орбите / летит → плечо J (или прыжок, §5) к точке рядом с
   её будущим положением; выравнивание глобальных векторов скорости (или выход на ту же орбиту
   рядом, вне зоны J 5 км); затем п. 1. Для летящей цели точка встречи пересчитывается по её
   вектору (упреждение) на каждом плече.

## 5. Расчёт: заряд, заправка, прыжки

- Маршрут = последовательность сегментов: внутрисистемные плечи J (расход по `jChargeRateTps` на
  профиле ускорения плеча), межсистемные прыжки (`meanJumpChargeT` × дальность / средняя).
- Прыжок длиннее дальности ядра → планировщик сам вставляет промежуточные точки прыжка (системы по
  пути), помечая их.
- Заряда не хватает с резервом 10 % → планировщик вставляет ближайший по пути хаб с заправкой
  (минимум добавленного времени) и помечает «добавлено: заправка». Нет такого хаба → отказ с
  причиной («не хватает 0.6 т; ближайшая заправка вне досягаемости»).
- Итоги: время, заряд по точкам (после каждой), резерв на финише.

## 6. Исполнение

Машина состояний по точкам; программа точки = цепочка существующих автопилотов:
плечо J (route leg) → [стыковка (доковый планировщик) | орбита | посадка (автопилот к телу /
площадка поселения)] → действие (стоянка-сервис) → [взлёт — НОВОЕ] → следующая точка.
⏸ / ПАУЗА — состояние «пилот», сервер не летит; ПРОДОЛЖИТЬ — новый расчёт от места.

## 7. Этапы реализации

- R1 — модель: программа и действия у точки (`NavigationWaypoint`), профиль прибытия только у
  корабля; окно со списком программ; РАССЧИТАТЬ / СТАРТ / ПАУЗА.
- R2 — исполнение: хаб (стыковка + заправка / ремонт как сервис-стоянка), орбита, посадка на тело и
  на площадку поселения; взлёт с поверхности до пола J.
- R3 — пауза и ручной режим, продолжение.
- R4 — планировщик заряда, автовставка заправки, итоги.
- R5 — встреча с кораблём (рядом / в другом месте / летящий).
- R6 — межсистемные прыжки и автовставка промежуточных систем (нужен рантайм прыжка).
- Торговля в действиях — когда F8 получит сделки.
