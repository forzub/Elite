# Позиционные обозначения кораблей — предложение

Статус: буквы классов **приняты автором** (2026-11-09); номер изделия = шифр из паспорта корабля (`model_code`: KB44, 和50, LM39, MJ65…). Реализовано: `tools/maintenance/build_ship_layout.py`.

## Решение автора

> Пока модели в игре каноном не считаем. Обратная задача: сначала наклепаем оборудование, потом соберём из него
> корабль. Код вида 46A1A3A5: каждый шифр A1 обозначает узел, A1A3 — субузел и т. д., причём обозначение исходит
> из **компоновки**, а не функциональности. Корпус 46; два двигательных отсека 46A1, 46A2; кабина-капсула 46A3.
> Двигательная группа: 46A1A1 — реактор, 46A1A2 — передний двигатель, 46A1A3 — задний. Пятак, функционально
> привязанный к двигателю, — 46A1A2PT1, если изделие пятака маркируется как PT.
> На функциональной схеме — связка «пятак — двигатель — реактор — двигатель — пятак», одна карточка с
> пометкой, что таких групп у корабля две: объединять по функциональности, а не по назначению.

## Это реальная система: позиционные обозначения (reference designations)

Ровно так устроены американские стандарты **ASME Y14.44** и **IEEE 200 / IEEE 315**:

- **Число впереди — номер изделия (unit)**: `46` — корпус / модель корабля (наш `model_code`).
- **A — сборочная единица (assembly), разборная**: её можно снять и заменить целиком. `46A1` — узел 1 изделия
  46, `46A1A2` — субузел 2 внутри узла 1, и так вглубь.
- **U — неразборный узел (inseparable assembly)**: чинится только целиком. У нас это **запечатанное ядро прыжка**.
- **Две буквы класса + номер — деталь внутри узла**: `46A1A2PT1` — деталь класса PT № 1 в субузле 46A1A2.
- Номер детали уникален внутри своего узла; полное обозначение уникально на корабле.

Про клапан: «MT» в этих стандартах нет. В IEEE 315 отдельной буквы для клапана нет (гидравлика — **HY**,
механическая деталь — **MP**). В схемах трубопроводов (ISA-5.1, P&ID) клапаны обозначают **V** (XV, FV…).
В европейском IEC 81346-2 управление потоком — класс **Q** (клапан — QM). Предлагаю для нас **VL**, как ниже.

## Две схемы одного корабля

1. **Компоновочная (дерево обозначений)** — где что стоит: `46 → 46A1 (двигательный отсек 1) → 46A1A2 (передний
   двигатель) → 46A1A2PT1 (его пятак)`. Источник обозначений для мануала, ремонта и каталога отказов: код
   неисправности ссылается на обозначение (`46A1A2PT1: RCT-01-W`).
2. **Функциональная (цепочки)** — как узлы работают вместе: карточка «пятак — двигатель — реактор — двигатель —
   пятак» с пометкой **×2** (группы в отсеках 46A1 и 46A2). Цепочки строятся из шин каталога отказов
   (силовая шина двигателей, охлаждение…) по компоновочному дереву, а не по категориям.

## Пример: Cobrett-I A3 (4 двигателя CR-1, 2 реактора ER-5)

```
44                     Cobrett-I A3 (корпус)
├─ 44A1                двигательный отсек левый
│  ├─ 44A1A1  GR1      реактор ER-5        ├─ PT1 пятак реактора
│  ├─ 44A1A2  ME1      передний CR-1       ├─ HX1, MP1 (привод цапфы)
│  └─ 44A1A3  ME2      задний CR-1         └─ HX1, MP1
├─ 44A2                двигательный отсек правый (то же)
├─ 44A3                кабина-капсула      EC1, LS1, BT1, CM1 (маяк SOS)
├─ 44A4                отсек систем        GS1 (ВСУ), CP1, RA1, CM2, TX1
├─ 44A5                контур охлаждения   PU1, WP1…, RD1…RD38 (панели)
├─ 44U1                ядро прыжка (неразборное) + TK1…TK3 (заряд)
└─ 44A6                грузовой отсек      CR1…CR6
Функционально: [PT — ME — GR — ME — PT] ×2 (44A1, 44A2)
```

Вопрос к автору: пятак — у реактора (физически реактор сбрасывает тепло через пятак) или у двигателя, как в
твоём примере `46A1A2PT1`? В нашем оборудовании пятак принадлежит реактору ER-5; у двигателя — теплообменник.

## Стандарт обозначений - у производителя (автор 2026-11-09)

> Не знаю, стоит ли американский стандарт применять ко всем кораблям; у китайцев он точно будет другим.

Принцип «по компоновке» общий, форма записи - своя у каждой промышленной культуры
(`ship_naming.json` -> `designation_standard`):

| Стандарт | Кто | Пример |
|---|---|---|
| ASME Y14.44 / IEEE 315 (американский) | Cobretty, Kern, Гиперион | `KB44A1A2PT1` |
| IEC 81346 (международный: `=` изделие, `+` отсек, `-` изделие класса IEC 81346-2) | ОФУ, Лунно-Марсианские верфи, Бхарат, Agora | `=LM39+1-M2-E1` |
| GB/T 5094 (китайская редакция IEC 81346) | Гармония, Тяньхэ | `=和50+1-M2-E1` |
| NORSOK (норвежские теги Северного моря) | Бастион | `MJ64-01-ME-001/PT1` |
| донор | Каменные доки (переделки сохраняют маркировку донора) | по донору |

Классы IEC 81346-2 (одна буква): M - двигатель / привод, G - реактор / генератор / насос, E - тепло (пятак,
радиатор, теплообменник), C - хранение (баки, батареи), Q - клапаны и форсунки, K - обработка сигналов (компьютер,
связь, платы), B - датчики и радары, H - производство (ЖО, кислород), U - крепление и стойки, X - стыковка,
F - защита (броня, теплозащита), A - многоцелевые узлы.

## Пятак двигателя (автор 2026-11-09)

У каждого двигателя свой охлаждающий пятак; тепло двигателя уходит в общий контур (через резервный
теплообменник) только при повреждённом пятаке. В каталоге отказов: `DRV-09` повреждение пятака двигателя ->
перегрев катушек (`DRV-02`), нагрузка на насос контура (`CLP-01`), постоянная работа теплообменника (`DRV-04`).

## Компоновка по умолчанию (генерируется из оборудования)

Двигательные отсеки - по числу групп «реактор + двигатели» (min из числа реакторов и двигателей, поровну); затем
кабина-капсула, бортовые системы, охлаждение, прыжковый, топливный, маневровые, груз, вооружение, стыковка,
корпус. Крупные узлы получают свой номер узла, мелкие массовые детали (панели радиатора, сопла RCS, баки,
стойки C20) - номер класса в отсеке. Ядро прыжка - неразборный узел (U). Авторская компоновка корабля позже
перекрывает сгенерированную. Коды функциональных групп паспортов переименованы в `<шифр>F<k>`.
