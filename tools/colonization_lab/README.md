# colonization_lab — офлайн-лаборатория истории, демографии и экономики колонизации

Маленькая детерминированная модель. Она **измеряет**, а не пишет историю: якоря канона применяются как есть, всё остальное вычисляется причинно и сравнивается с авторскими числами. Вероятности (например, ответ общества на шок) лаборатория сообщает, но события не навязывает.

Вход:
- `canon/missions.json` — паспорта миссий и исторические якоря (с полем `knowledge` у миссии, полей и каждого якоря);
- `canon/world.json` — колонии, аванпосты, фронтиры, маяки, обиды, хронология гипера, якорь Земли-3126, входы демографии (`demography`, `earth_demography`, `demography_events`, `migration`, `jump_technology`), неизвестные (`unknowns`);
- `canon/cultures.json` — культуры источников и фильтры набора;
- `canon/settlements.json` — ключевые поселения и площадки на телах каталога (всё PROPOSAL);
- физический каталог `src/assets/data/galaxy_details` — читается через `endowment.py` и `tools/universe_generator/resource_audit.py`.

Выход (`out/`):
- `lab_report.md` — отчёт: миссии, хроники, физика, **§D демография**, колонии, экономика, **§T торговые коридоры и пересмотр навалочных грузов**, шоки, социальные ответы, **§E «Возвращение Земли»**, реакции, отношения, сеть;
- `lab_state_3126.json` — всё то же машинно (`demography`, `trade`, `earth_return`);
- `lore_facts.json` — факты для лорщиков: у каждой записи статус и видимость;
- `proposals.md` — список всего, что не является публичным каноном автора (PROPOSAL, AUTHOR_TRUTH, UNKNOWN).

Только стандартная библиотека Python 3.

## Команды

```bash
cd tools/colonization_lab
python lab.py                        # канон: seed 3126 -> out/
python lab.py --seed 7 --out D:/tmp/elite_x  # другой seed меняет только заполняющие события и эпидемии, не якоря
python lab.py --check-dataset        # runtime generation_ships.json не разошёлся с каноном (включая статусы)?
python lab.py --check-lore           # out/lore_facts.json совпадает с каноном и со свежей сборкой?
python export_runtime.py --write     # регенерировать блок canon в src/assets/data/galaxy/generation_ships.json (после lab.py)
python knowledge.py [--write]        # пересчитать статусы знаний в canon/*.json (идемпотентно)
python lore.py --propose-settlements # добавить заготовки поселений для новых политий (существующие не трогает)
python endowment.py                  # индексы ресурсов и площадки поселений из каталога
python lore_md.py --write             # обновить блоки GENERATED справочника Notes/Lore/ (после lab.py); --check — блоки, id сущностей и числа населения в рассказе сверены с данными
```

## Доказательство детерминизма

Нет часов, нет несидированного RNG, итерация отсортирована. RNG миссии = `seed * 1000003 + crc32(id)`, RNG демографической единицы = `seed * 7919 + crc32(id)`.

```bash
python lab.py --out D:/tmp/elite_labA && python lab.py --out D:/tmp/elite_labB && diff -r D:/tmp/elite_labA D:/tmp/elite_labB && echo IDENTICAL
```

Программа печатает sha256 от всех четырёх выходов:

```text
seed=3126 missions=36 colonies=22 earth=5998607890 off_sol=183356200 sha256=0f6bce190a7eb46dec5048e261547ffc99d8edaeb45a96bf412692d4e03d7bff  (прогон 2026-11-02; меняется при любом изменении canon/*.json или кода)
```

## Статусы знаний (knowledge.py)

- `status`: **CANON** — есть в заметках автора (`Notes/History/generation ships/*`, `Notes/History/generation ships.md`, `Notes/fate.md`, `Notes/History/history.md`, каталог); **PROPOSAL** — добавлено или пересчитано Claude, а также любой результат модели; **UNKNOWN** — намеренно без ответа, даже для автора.
- `visibility`: **PUBLIC_RECORD** — мир 3126 это знает или может знать; **AUTHOR_TRUTH** — скрытая правда автора.
- Правило для событий проверяемо: якорь — CANON, если его год встречается в исходных файлах его миссии. Пересчитанное значение хранит авторское в `authored` и получает PROPOSAL. Явные изобретения реконсиляции перечислены в `knowledge.OVERRIDES`. `hidden_truth` даёт отдельную запись AUTHOR_TRUTH.

## Правила

- **Якоря** (`anchors`) — записанная история: смерти, эффекты, численность на прибытии. Модель не может их переписать.
- **Заполняющие события** (`source: simulated`) — только мелкие и seed-зависимые.
- **Население не задаётся.** `pop_3126_authored` — авторское число; модель (`demography.py`) считает население причинно. Расхождение больше чем в 2 раза печатается как конфликт (отчёт §D.8), а не переписывает канон.
- Даты прибытия выводятся из расстояния в каталоге. Исправленные даты хранят старое значение в поле `authored`.
- Навалочный груз между звёздами допускается только при конкретной причине: нет своего источника, свой источник дороже доставленного импорта, внутрисистемная торговля. Каждый коридор несёт причину, альтернативы, узкие места, контролёра и ставку фрахта безубыточности.

## Модель демографии (кратко)

Год за годом, для каждой колонии, аванпоста, фронтира и двух регионов Земли (возрастная структура по 5-летним группам):
1. **Экономика детей:** жильё = построенный объём (купола → луны/астероиды → цилиндры, ярусы и рента по телам каталога); ценность детского труда = (1 − автоматизация) × дефицит рук; пенсии; длина образования; детская смертность.
2. **Семейная норма** следует за экономикой с запаздыванием ~45 лет (в обе стороны).
3. **Религиозная субкультура:** своя рождаемость, отток и приток.
4. **Политика режима** и лицензии на рождение при заполненных хабитатах.
5. **Смертность** из таблицы жизни по медицине и уровню жизни; сидированные эпидемии; войны из якорей.
6. **Технологии по 12 областям:** у каждой критическая масса специалистов. Возможны деградация, каннибализация машин, восстановление, импорт, кража, гостайна (ядра прыжка).
7. **Миграция** только после 2750, по графу маяков, с ограниченными местами в кораблях и барьерами режимов. Земля участвует через окна (Кордон 2790–3112).

Допущения F1–F12 и исторические данные — `D:/tmp/DEMOGRAPHY_RESEARCH.md`. Сценарии: `baseline` и `transition_persists` (без F9/F10). Отчёт печатает оба.

## Состав

| Файл | Что делает |
|---|---|
| `endowment.py` | индексы ресурсов по каталогу; площадки поселений, малые тела, пояса |
| `physics.py` | порядок величины для кораблей: масса, He-3, ускорение, радиаторы, вердикт |
| `demography.py` | причинная демография, технологии, миграция, траектории |
| `trade.py` | рынок 3126: товары с массой, фрахт, правило своего источника, коридоры |
| `knowledge.py` | статусы CANON / PROPOSAL / UNKNOWN и PUBLIC_RECORD / AUTHOR_TRUTH |
| `lore.py` | `lore_facts.json`, `proposals.md`, заготовки поселений, проверка `--check-lore` |
| `lab.py` | вахта, крио, общество (Colonycore v2), сеть маяков, сборка прогона, шоки, ответы, «Возвращение Земли», отчёт, проверки; старый рынок `LegacyEconomy` оставлен только для сравнения потоков |
| `export_runtime.py` | канон → `generation_ships.json`: legacy-поля сохранены, блок `canon` со статусами |

Документы: `Notes/History/COLONIZATION_CANON_3126.md` (справочник), `Notes/Colonycore/COLONYCORE_V2.md` (модель общества).

## Синхронизация Markdown и runtime

Источник истины — `canon/*.json`. Порядок обновления:
1. `python knowledge.py --write` (если менялся канон);
2. `python lab.py`;
3. `python export_runtime.py --write`;
4. `python lab.py --check-dataset`;
5. `python lab.py --check-lore`.
6. `python lore_md.py --write` и `python lore_md.py --check` — справочник `Notes/Lore/` (таблицы генерируются, рассказ вне маркеров сохраняется).

Markdown-справочник пишется вручную по отчёту. Его таблицы населения (§8–§9) **устарели**: там авторские числа, а модель считает население причинно (отчёт §D).
