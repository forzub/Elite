# Astronaut model license records

Downloaded astronaut model binaries are kept outside Git under:

```text
D:\__elite\work\assets\models\astronauts\
```

Each astronaut gets its own local directory and matching documentation directory here.

Recommended sequence:

```text
lumi_001
milo_002
nori_003
piko_004
```

For each downloaded model create:

```text
ASSET_LICENSES/models/astronauts/<code>/README.md
```

and use the same `<code>` for the local binary directory:

```text
D:\__elite\work\assets\models\astronauts\<code>\
```

The per-model README should record the original model title, author, source URL, download date, exact license, original downloaded format/file, attribution obligations, modification/redistribution permissions, local path, and any later processing performed on the model.
