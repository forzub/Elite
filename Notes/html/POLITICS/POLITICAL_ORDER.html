Правило разрешения: 1. Единица -> актор (провинция -> её актор; специальная зона -> собственный профиль зоны). 2. Один и тот же актор -> 0 во всех категориях (внутренний рынок). 3. Оба актора в одном блоке -> bloc.internal; если хотя бы один — associate, то bloc.associate_internal. 4. Иначе access(продавец -> покупатель)[c] = max(export(продавец)[c], import(покупатель)[c]); export / import — профиль неприсоединившегося актора или блока. 5. Исключения (exceptions): если актор исключения — одна из сторон и партнёр в scope, то access[c] = min(access[c], cap[c]). Зоны исключениям не подчиняются, если не названы в scope явно. 6. Санкции (sanctions): каждая действующая мера, совпавшая по направлению и единицам, поднимает access[c] = max(access[c], level[c]). Санкции применяются после исключений: мера против самого исключённого актора действует. 7. Транзит: если санкция закрыла (4) гражданскую или промышленную категорию, а транзитный хаб (exception kind transit_hub) имеет <= 1 с обеими сторонами, остаётся 3 (косвенно, через хаб).
